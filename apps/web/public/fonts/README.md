# Material Symbols Outlined

Fonte oficial do Google, servida localmente para que os ícones não dependam do acesso a fonts.googleapis.com em tempo de execução. Licença Apache 2.0 em LICENSE-material-symbols.txt.

Subset com peso 400, tamanho óptico 24, grade 0 e eixo FILL de 0 a 1 (inclui estrelas preenchidas da watchlist).

Ícones incluídos: account_balance, account_balance_wallet, account_circle, add, arrow_drop_down, arrow_drop_up, bar_chart, close, currency_bitcoin, currency_exchange, dashboard, edit_note, logout, more_vert, newspaper, notifications, public, refresh, search, settings, show_chart, star, sync_alt, trending_up, tune.

Ao adicionar ícones, atualize o subset usando a API oficial:
https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@24,400,0..1,0&icon_names=account_balance,account_balance_wallet,account_circle,add,arrow_drop_down,arrow_drop_up,bar_chart,close,currency_bitcoin,currency_exchange,dashboard,edit_note,logout,more_vert,newspaper,notifications,public,refresh,search,settings,show_chart,star,sync_alt,trending_up,tune
